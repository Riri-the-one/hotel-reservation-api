# Preserved Vite prototype — inactive

This directory is the original standalone React/Vite starter. It is not connected to the hotel's booking backend and is not the supported interface.

The working React application lives in [backend/resources/js](../backend/resources/js) and is served by Laravel through Inertia. Keeping a single interface avoids duplicate authentication, routing and booking flows.

No prototype source has been deleted. This folder is excluded from application CI and should not be used to demonstrate implemented booking features. Follow the [root README](../../README.md).
